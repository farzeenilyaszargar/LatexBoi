# Unleaf

![Unleaf — the no-login LaTeX editor](https://www.unleaf.lol/unleaf-social.png)

**Unleaf** is a free, no-login LaTeX editor for writing research papers with live preview, autocomplete, local drafts, and PDF export.

Visit the website: [www.unleaf.lol](https://www.unleaf.lol)

```bash
npm install
npm run dev
```
